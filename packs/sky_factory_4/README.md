# 🌌 SkyFactory 4 – Modpack Download & Install Guide

Welcome to the SkyFactory 4 server! This guide will show you exactly how to download the pack from CurseForge and connect to the server.

---

## 📦 1. Download SkyFactory 4 (Client Modpack)

We use the official modpack from CurseForge.

### **CurseForge Download Link**
🔗 https://www.curseforge.com/minecraft/modpacks/skyfactory-4

### **Steps**
1. Install the CurseForge App  
   → https://www.curseforge.com/download/app  
2. Open CurseForge and click the **Minecraft** icon.  
3. Search for: **SkyFactory 4**  
4. Click **Install**  
5. Wait for the modpack to finish preparing.

---

## 🖥️ 2. Launch SkyFactory 4

1. In CurseForge, click **Play**.  
2. This will launch the modpack inside the Minecraft Launcher.  
3. Make sure you select the correct **Forge version** if asked.

## 🛠️ Common Fixes

### **Game won’t launch**
- Allocate at least **6–8GB RAM** in CurseForge → Settings → Minecraft → Java Arguments.

### **Mod mismatch**
- Make sure you installed the **official SkyFactory 4** modpack, not a custom version.

### **Server says “Missing Mods”**
- Update the pack:
  CurseForge → SkyFactory 4 → **Update** or **Reinstall**

---

## 📝 Notes
- This modpack is large — your first startup may take several minutes.
- If you crash on world load, increase RAM or update Java 8.
