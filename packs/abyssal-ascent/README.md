# 🕳️ Abyssal Ascent – Modpack Download & Install Guide

Welcome to the Abyssal Ascent server! This guide shows how to download the modpack via CurseForge and connect to your world.

---

## 📦 1. Download Abyssal Ascent (Client Modpack)

### **CurseForge Modpack Page**
🔗 https://www.curseforge.com/minecraft/modpacks/abyssal-ascent

### Steps:
1. Download & install the CurseForge App:  
   https://www.curseforge.com/download/app
2. Open the app and click **Minecraft**.
3. Search for **Abyssal Ascent**.
4. Click **Install**.
5. Wait for the modpack to finish installing.

---

## 🖥️ 2. Launch Abyssal Ascent

1. Go to the modpack in CurseForge.
2. Press **Play**.
3. Minecraft Launcher will open with the correct profile.

---

## 🛠️ Troubleshooting

### **Stuck loading / slow startup**
- Allocate more RAM (6–10GB recommended)
- Close Chrome or other memory-heavy apps

### **Missing Mods error**
- Open CurseForge → Abyssal Ascent → **Update**  
- Or reinstall the pack

### **"Server mod list is incompatible"**
- Make sure your modpack version matches the server version.
