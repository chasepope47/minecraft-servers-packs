## 🎮 Optional Settings for Better Gameplay

### **Turn On "Allow Server Resource Packs"**
Some servers use resource packs for custom visuals.

Steps:
1. Multiplayer → Select the server.  
2. Click **Edit**.  
3. Set **Server Resource Packs: Enabled**.

---

## 🛠️ Troubleshooting

### **Can't connect?**
Check:
- You're using **Java Edition**, not Bedrock.
- You're on **the same version** the server is running.
- Your firewall or antivirus isn't blocking Minecraft.

### **Outdated Client / Outdated Server**
- Change your Minecraft version:  
  Launcher → Installations → New Installation → Choose the correct version.
