# 🎮 Minecraft Server Pack Repo
## 🚀 How to Install CurseForge & Get Started

To play on any of our servers, you’ll need to have the **CurseForge App** installed.  
Follow the steps below to get everything set up!

---

## 🧭 1. Download the CurseForge App

1. Open your web browser.
2. Go to 👉 https://www.curseforge.com/download  
3. Click **Download for Windows** to get the installer (`.exe`).

---

## ⚙️ 2. Install CurseForge

1. Open your **Downloads** folder.
2. Run the installer.
3. When Windows prompts:

   > “Allow this app to make changes?”

   Click **✔️ Yes**.

4. Follow the installation steps:
   - 📄 Accept the License Agreement  
   - 📁 Choose an install location  
   - ▶️ Click Install

---

## ⛏️ 3. Select Minecraft in CurseForge

1. Launch **CurseForge**.
2. Click the **Minecraft** icon.
3. If asked to locate Minecraft, either:
   - Let CurseForge auto-detect, or  
   - Manually select:

     ```
     C:\Users\<YourName>\AppData\Roaming\.minecraft
     ```

---

## 🔧 4. Install Required Mod Loaders

CurseForge will automatically install the required mod loader for any pack:

- 🔩 Forge  
- 🧶 Fabric  
- 🪶 Quilt  

If prompted, click **✔️ Yes** to allow installation.

---

## 📦 5. Install a Modpack

1. Go to **Browse Modpacks**.
2. Search for your desired pack (e.g., *SkyFactory 4*, *Abyssal Ascent*, *BetterMC*).
3. Click **📥 Install**.
4. Wait for the download — large modpacks can take several minutes.

---

## ▶️ 6. Launch Your Modpack

1. Open **My Modpacks**.
2. Click **Play** on your chosen pack.
3. The **Minecraft Launcher** will open.
4. Select the autogenerated profile.
5. Click **▶️ Play** again.

> ⏳ **Note:** Large modpacks may take several minutes on first launch.  
> “Preparing…” or “Warming Up JVM” is totally normal.

---

## ⚡ 7. Recommended Settings — RAM Allocation

Boost performance by increasing RAM:

1. Click the **⚙️ Settings** icon.
2. Select **Minecraft** settings.
3. Adjust **Allocated Memory**:
   - 🟦 4–6 GB → Light modpacks  
   - 🟩 6–8 GB → Heavy modpacks (BetterMC, All the Mods)

**⚠️ Avoid allocating more than ~70% of your PC’s RAM.**

---

## 🛠️ 8. Troubleshooting (Quick Fixes)

### ❌ Minecraft won’t launch
- RAM too high/low  
- Corrupted modpack → reinstall  
- Ensure Java is installed (CurseForge often handles this)

### ❌ “Profile Not Found”
- Run CurseForge as **Administrator**  
- Reinstall the mod loader / pack

### ❌ Downloads stuck
- Restart CurseForge  
- Check internet  
- Make sure antivirus isn’t blocking it
