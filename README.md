How to Install CurseForge & Get Started

To play on any of our servers, you’ll need to have the CurseForge App installed.
Follow the quick and easy steps below.

🚀 1. Download the CurseForge App

Open your web browser.

Go to: https://www.curseforge.com/download

Click Download for Windows to download the installer (.exe).

⚙️ 2. Install CurseForge

Open your Downloads folder.

Run the installer.

If Windows prompts you:

“Allow this app to make changes?”
Click Yes.

Follow the installation steps:

Accept the License Agreement

Choose an installation location (default is recommended)

Click Install

🎮 3. Select Minecraft in CurseForge

After installation, open the CurseForge App.

Click Minecraft from the game list.

CurseForge may auto-detect your Minecraft installation.

Click Yes if prompted.

Or manually locate it at:

C:\Users\<YourName>\AppData\Roaming\.minecraft

🔧 4. Install Required Mod Loaders

CurseForge will automatically install whatever the modpack requires:

Forge

Fabric

Quilt

If CurseForge asks permission to install these → click ✔ Yes.

📦 5. Install a Modpack

Go to Browse Modpacks.

Search for the pack you want (SkyFactory 4, Abyssal Ascent, BetterMC, etc.).

Click Install.

Wait for the modpack to download — large modpacks can take several minutes.

▶️ 6. Launch Your Modpack

Open the My Modpacks tab.

Click Play.

The Minecraft Launcher will open automatically.

Select the generated profile and click Play.

⏳ First launch may take several minutes.
“Preparing” or “Warming Up JVM” is normal for heavy modpacks.

⚡ 7. Recommended Settings (RAM Allocation)

Some modpacks need more memory to run smoothly.

Click the Settings (gear icon) in CurseForge.

Select Minecraft.

Change Allocated Memory:

4–6 GB → lighter modpacks

6–8 GB → heavy modpacks (BetterMC, All the Mods)

⚠️ Do not exceed ~70% of your total system RAM.

🛠️ Common Issues & Fixes
❌ Minecraft Won’t Launch

RAM too high or too low

Modpack corrupted → reinstall

Make sure Java is installed (CurseForge often installs its own)

❌ “Profile Not Found”

Run CurseForge as Administrator

Reinstall the mod loader or modpack

❌ Downloads Are Stuck

Restart CurseForge

Check your internet connection

Ensure antivirus or Windows Defender isn’t blocking it

🌐 Optional: Use Standalone CurseForge (No Overwolf)

Prefer the Overwolf-free version?

👉 Download here: https://download.curseforge.com

Choose “CurseForge App (Standalone)”

🎉 You’re Ready to Play!

Once your modpack is installed, launch Minecraft and enjoy your adventure on our servers.
