# Minecraft Server Pack Repo
## How to Install CurseForge & Get Started

To play on any of our servers, you’ll need to have the **CurseForge App** installed.  
Follow the quick and easy steps below.

---

## 1. Download the CurseForge App

1. Open your web browser.
2. Go to: https://www.curseforge.com/download  
3. Click **Download for Windows** to download the installer (`.exe`).

---

## 2. Install CurseForge

1. Open your **Downloads** folder.
2. Run the installer.
3. If Windows prompts you:

   > “Allow this app to make changes?”

   Click **Yes**.

4. Follow the installation steps:
   - Accept the License Agreement  
   - Choose an installation location (default is recommended)  
   - Click **Install**

---

## 3. Select Minecraft in CurseForge

1. Open the **CurseForge App**.
2. Click **Minecraft** from the game list.
3. If CurseForge asks to locate your Minecraft folder, either:
   - Let it auto-detect, or  
   - Manually select:

     `C:\Users\<YourName>\AppData\Roaming\.minecraft`

---

## 4. Install Required Mod Loaders

CurseForge will automatically install any mod loader your pack needs, such as:

- Forge  
- Fabric  
- Quilt  

If CurseForge asks to install these, click **Yes**.

---

## 5. Install a Modpack

1. Go to the **Browse Modpacks** tab.
2. Search for the modpack you want (e.g., *SkyFactory 4*, *Abyssal Ascent*, *BetterMC*).
3. Click **Install**.
4. Wait for the download to finish. Large modpacks can take several minutes.

---

## 6. Launch Your Modpack

1. Open the **My Modpacks** tab.
2. Click **Play** on the modpack.
3. The **Minecraft Launcher** will open automatically.
4. Select the profile created by CurseForge.
5. Click **Play**.

> First launch of a big modpack may take several minutes.  
> Seeing “Preparing” or “Warming Up JVM” is normal.

---

## 7. Recommended Settings (RAM Allocation)

Some modpacks need extra memory to run smoothly.

1. In CurseForge, click the **Settings** (gear) icon.
2. Select the **Minecraft** section.
3. Under **Allocated Memory**, set:
   - **4–6 GB** for lighter modpacks  
   - **6–8 GB** for heavier modpacks (BetterMC, All the Mods, etc.)

**Do not allocate more than about 70% of your total system RAM.**

---

## 8. Common Issues & Fixes

### Minecraft won’t launch
- Check that your RAM setting isn’t too high or too low.
- Try reinstalling the modpack.
- Make sure Java is installed (CurseForge often installs its own).

### “Profile Not Found”
- Run CurseForge as **Administrator**.
- Reinstall the mod loader or the modpack.

### Downloads are stuck
- Restart CurseForge.
- Check your internet connection.
- Ensure antivirus or Windows Defender isn’t blocking CurseForge.

---

---

You’re now ready to install our server packs and start playing!
