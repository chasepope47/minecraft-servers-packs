Welcome to the Minecraft Server Pack Repo!
To play any of the servers we have listed please make sure to have CurseForge downloaded.
  1. Download the CurseForge App
    Open your web browser (Chrome, Edge, Firefox).
    Go to the official website:
    https://www.curseforge.com/download
    Click Download for Windows.
    This will download the CurseForge Installer (a .exe file).

  2. Run the Installer
    Locate the downloaded file (usually in Downloads folder).
    Double-click the installer.
    If Windows asks “Do you want to allow this app to make changes?” → click Yes.
    Follow the installer steps:
    Accept License Agreement
    Choose an install location (default is fine)
    Click Install

  3. Select a Game (Minecraft)
    Once CurseForge opens, choose Minecraft
    The app may ask to locate your Minecraft installation
    Click Yes, locate it automatically
  OR
    Browse to:
    C:\Users\<YourName>\AppData\Roaming\.minecraft
    CurseForge will verify that Minecraft is installed.

  4. Install Required Minecraft Tools
    CurseForge needs one of the following for modpacks: Forge, Fabric, Quilt
    CurseForge installs these automatically when you install a modpack.
    If asked:
      ✔ Click Yes to allow it to install the necessary mod loader.
 5. Install a Modpack
    Go to the Browse Modpacks tab.
    Search for the modpack you want (ex: SkyFactory 4, Abyssal Ascent, BetterMC).
    Click the modpack.
    Hit Install.
    Wait — modpacks can be large (100–300 mods) and may take a few minutes.

  6. Launch a Modpack
    After installation, go to the My Modpacks tab.
    Click Play on the modpack.
    This opens the Minecraft Launcher.
    Choose the automatically created profile.
    Click Play.
    If it’s your first time launching a large modpack:
    Expect a long “Preparing” or “Warming up JVM” screen.
    This is normal.

  7. Recommended Settings
    Increase RAM (Optional but helps a LOT)
    Click the Settings (gear) in CurseForge.
    Go to Minecraft section.
    Under Allocated Memory, set:
    4–6 GB for lighter modpacks
    6–8 GB for heavy modpacks (BetterMC, All the Mods, etc.)
    **Do not exceed 70% of your total RAM.**

**Common Issues & Fixes**
❌ Minecraft won’t launch
      Check RAM settings — too high or too low can break things.
      Try reinstalling the modpack.
      Make sure Java is installed (CurseForge often installs its own).

❌ “Profile Not Found”
      Run CurseForge as Administrator.
      Reinstall the modpack or the mod loader.

❌ Download stuck
      Check your internet connection.
      Restart CurseForge.
      Ensure Windows Defender or antivirus isn’t blocking it.
